# Charles Proxy: Тестирование безопасности и работа с трафиком

## Выполненные кейсы

### 1. Подмена количества товаров в корзине
**Задача:** В запросе отправляется "2 товара", вернуть "500".  
**Решение:** Использован инструмент **Rewrite** в Charles Proxy для подмены тела ответа. 

**Результат:**  
Сервер вернул значение "500" вместо фактического количества товаров.

### 2. Подмена статус-кода ответа

**Задача:** Заставить сервер отдавать статус 403 на запрос к главной странице, не затрагивая другие ресурсы.

**Решение:** Использован инструмент **Block List** в Charles Proxy:
- Включена блокировка для `intern.demoshopping.ru`
- Выбрано действие: `Return 403 response`

**Результат:**  
Браузер получил ответ с кодом 403, остальные сайты работают штатно.

### 3. IDOR: удаление чужого товара из корзины

**Задача:**  
При удалении товара из корзины изменить запрос так, чтобы удалился другой товар.

**Решение:**  
Использован инструмент **Breakpoints** в Charles Proxy:
- Установлен Breakpoint на DELETE-запрос к `intern.demoshopping.ru`
- Перехвачен запрос, изменён ID товара на другой
- Запрос отправлен на сервер

**Результат:**  
Сервер удалил товар, не принадлежащий текущему пользователю (обнаружена IDOR-уязвимость).

### 4. Подмена картинки на сайте

**Задача:**  
Вместо страницы интернет-магазина пользователь видет любую другую картинку.

**Решение:**  
Инструмент **Map Local** в Charles Proxy.  Ответ сервера подменён на локальный файл с изображением.

**Результат:**  
При загрузке сайта отображается заданная картинка вместо каталога товаров.

### 5. Перенаправление запросов с Prod на Stage 

**Задача:**  
`intern.demoshopping.ru` — это Prod, а `stage.demoshopping.ru` — Stage. Настроить перенаправление запросов с Prod на Stage.

**Решение:**  
Инструмент **Map Remote** в Charles Proxy.
Инструмент **Map Remote** в Charles Proxy:
- **Map From:** `intern.demoshopping.ru` (Prod)
- **Map To:** `stage.demoshopping.ru` (Stage)
- Путь: `/` → `\0` (исходный путь сохраняется)

**Результат:**  
Открывая Prod-ссылку, браузер получает ответ от Stage-окружения.

### 6. Перехват HTTPS-запроса с мобильного устройства (User-Agent)

**Задача:**  
Перехватить запрос с реального Android-устройства и показать заголовок User-Agent.

**Решение:**  
Charles Proxy настроен для работы с мобильным трафиком, установлен SSL-сертификат. На устройстве открыт сайт интернет-магазина.

**Результат:**  
В заголовке User-Agent отобразилась информация об устройстве: `Android 10; Mobile; Chrome/144`.
